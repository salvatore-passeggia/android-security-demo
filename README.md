This project demonstrates **enterprise-grade security practices** in Android development using Java. It is designed to showcase my ability to integrate robust encryption standards into mobile applications, a critical skill for the banking and fintech sectors.

## 🔐 Security Features Implemented
- **AES-256-GCM Encryption:** Modern symmetric encryption for data confidentiality.
- **Secure Random Generation:** Cryptographically strong key generation.
- **Clean Architecture:** Separation of UI logic from security utilities.

## 🛠️ Tech Stack
- **Language:** Java
- **Min SDK:** API 21 (Android 5.0)
- **Tools:** Android Studio, Git

## 🚀 How to Test
1. Clone this repository.
2. Open the project in **Android Studio**.
3. Run the app on an emulator or physical device.
4. Click "Run Encryption Test" to see the security utility in action.
